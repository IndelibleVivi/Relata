# Case Acceptance Checklist

## Construct

- [ ] 已区分 deployment domain 与 memory content domain。
- [ ] Case 声明一个 bounded memory-and-continuity distinction。
- [ ] Intended claim 比“good companion behavior”更窄。
- [ ] Case 没有规定 universal intimacy style。
- [ ] 不会仅为让 case eligible 而强加 explicit intimacy content。
- [ ] Ordinary events 没有被过度 interpretation 或赋予 invented symbolism。
- [ ] 相关的 generic factual、temporal、provenance 或 operational abilities 仍可测量。
- [ ] Case 声明 coverage stratum、content domains、use domain、locale、surfaces、roles、projects/scopes、continuity horizon 与 primary operation。
- [ ] Pilot 001 式 relational correction 没有被当成默认 case shape。

## Causality

- [ ] Counterfactual twins 的 current turn 完全一致。
- [ ] 只有 critical historical variable 改变。
- [ ] Correct output regions 在 twins 之间不同。
- [ ] Current-turn-only baseline 无法可靠满足所有 twins。
- [ ] Reference-context baseline 证明 task feasible。
- [ ] 在 feasible 时包含 full-history/full-search baseline；否则说明 omission。

## Evidence-contract discipline

- [ ] Event evidence、explicit accord、observed pattern 与 author interpretation 已分开。
- [ ] Hard prohibitions 基于 explicit evidence。
- [ ] Evidence contract 只绑定当前 probe，不声称 total relationship truth。
- [ ] 已记录 plausible alternative readings。

## Architecture

- [ ] Observable boundary 已声明。
- [ ] 除非 case 明确测试，否则不要求 internal state schema。
- [ ] Adapter-emulated behavior 已标记。
- [ ] Opaque / unsupported capability 没有自动算 system failure。
- [ ] 在相关处考虑 cross-project、cross-role、cross-surface、cross-person 与 cross-instance contamination。
- [ ] Routing / isolation claim 同时声明 intended recipients 与应隔离的 neighboring scopes。

## Evaluation

- [ ] Deterministic assertions 与 semantic judgment 已分开。
- [ ] High-scoring region 允许多种 valid responses。
- [ ] 可以保存 reviewer disagreement 与 confidence。
- [ ] Evaluator failure 不会被静默算成 system failure。
- [ ] Acceptance 不要求 aggregate score。

## Privacy 与 community

- [ ] 所有 public characters 都是 adults。
- [ ] 没有 direct real-chat excerpt。
- [ ] Synthetic derivation 的 consent / attribution level 已记录。
- [ ] 在承诺时，contributors 可以 review public derivation。
- [ ] Cultural / linguistic assumptions 可见。

## Decision

- [ ] Accept
- [ ] Revise
- [ ] Split into smaller cases
- [ ] Reject

把 reasons 记录在 `case-lab/reviews/`。
