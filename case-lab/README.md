# Relata Case Lab

The Case Lab builds minimal adult synthetic cases that isolate one relational-memory distinction at a time.

The unit of work is a **Relational Critical Incident Chain**, not a long synthetic relationship world.

A chain contains:

- a minimal history;
- one bounded distinction;
- a current probe;
- one or more counterfactual twins;
- a probe-bounded evidence contract;
- baseline controls;
- architecture assumptions;
- ambiguity and privacy analysis;
- an expected failure-attribution map.

Long worlds may later compose accepted chains. Length is not evidence of validity.
