# Case Reviews

Store one review file per case and review round:

```text
RC-001-review-01.md
```

A review records:

- reviewers and disclosed perspective pool;
- baseline outputs examined;
- checklist result;
- disagreements;
- requested changes;
- accept/revise/split/reject decision;
- links to preserved pilot artifacts.
