# Relata Case Lab

Case Lab 在成人长期人机关系中构建最小 synthetic cases，每次只隔离一个 memory-and-continuity distinction。

## Coverage strata

- `personal-lived` — ordinary life、people、places、interests、study、health、travel、media 与 changing circumstances；
- `shared-relational` — shared experience、private language、norms、permissions、correction 与 repair；
- `operational-project` — projects、artifacts、tasks、blockers、decisions、rationale、milestones、handoffs 与 unfinished work；
- `companion-system` — companion identity、capabilities、limitations、models、providers、instances 与 migration；
- `mixed-domain` — 以上两个或更多 domains 之间的 routing、isolation 或 interaction。

这些 strata 描述 coverage，不是永久 benchmark tracks 或 mutually exclusive memory types。一张 case 可以声明多个 content domains，同时选择一个 primary coverage stratum。

工作单位是 **Relata Critical Incident Chain**，不是长篇 synthetic relationship world。

一条 chain 包含：

- minimal history；
- 一个 bounded distinction；
- current probe；
- 一组或多组 counterfactual twins；
- probe-bounded evidence contract；
- baseline controls；
- architecture assumptions；
- ambiguity / privacy analysis；
- expected failure-attribution map。

未来的 long world 可以组合 accepted chains。Length 不等于 validity evidence。Ordinary information 应保持 ordinary，除非 bounded construct 的 evidence 本身要求 relational significance。Pilot 001 只是一张 `shared-relational` current-state-use case，不是 Relata 的默认 case shape，也不代表 complete scope。
