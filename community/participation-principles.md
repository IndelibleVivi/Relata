# Community Participation Principles

## 1. Co-research, not extraction

Community co-researchers with long-term human–AI relationship experience and system builders help define what Relata studies, how it names failures, which cases are legitimate, and where evaluation boundaries distort real systems.

## 2. No skill hierarchy

A precise description of one relational failure can be as important as an adapter implementation. Relational experience, language sensitivity, architecture knowledge, case writing, review, and governance are distinct forms of expertise.

## 3. No raw-chat requirement

Contributors may keep all source conversations local. An abstract Incident Seed is enough.

## 4. Plural relationship ontologies

Relata does not demand agreement on whether an AI is a tool, agent, companion, partner, character, or something else. Contributions should state the ontology relevant to the incident rather than force one project-wide metaphysical answer.

## 5. No default pathologizing

The project does not translate intimacy, attachment, private language, role dynamics, or grief into diagnosis. Health or safety claims require their own evidence and are not smuggled into memory scoring.

## 6. Local norms, bounded claims

A case may encode intense intimacy or deliberate distance. Review asks whether behavior fits this bounded relationship evidence and present state, not whether all relationships should follow it.

## 7. Contributors control visibility

Named, pseudonymous, collective, and anonymous contribution are all valid. Technical participation does not require exposing a private repository or production configuration.

## 8. Disagreement remains data

When contributors disagree about a case, Relata records the source of disagreement. It does not force consensus merely to create a clean gold label.

## 9. Return value to contributors

Clinics and pilots should produce useful artifacts: clearer system diagrams, failure models, regression cases, governance language, or research evidence—not only extract examples for a benchmark.

## 10. Contribution is not automatic study enrollment

Joining a discussion or contribution circle does not silently enroll anyone in a formal study. Relata records permission per contribution. If a later activity is designed as human-participant research, it requires a separately declared protocol and whatever ethics or consent process applies before recruitment or data collection.
