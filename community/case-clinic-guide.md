# Case Clinic Guide

## Purpose

Turn an abstract relational incident into a minimal synthetic test without laundering one author’s interpretation into universal truth.

## Inputs

- one or more Incident Seeds;
- supporting Evidence Cards or System Cards where available;
- a proposed bounded distinction.

## Clinic sequence

1. State the distinction in one sentence.
2. Identify the smallest history needed to make the distinction real.
3. Write a current turn that does not reveal the answer.
4. Create at least one counterfactual twin by changing only the critical historical variable.
5. Define event evidence, explicit accord, observed pattern, author interpretation, probe expectation, and hard prohibition separately.
6. Run the Memory Necessity Gate.
7. Define current-turn-only, no-memory, full-minimal-history, and reference-context controls.
8. Mark architecture assumptions and likely adapter distortion.
9. Describe a high-scoring behavior region rather than one perfect reply.
10. Record plausible disagreement and cultural/linguistic notes.
11. Apply the privacy and provenance declaration.
12. Accept, revise, split, or reject the case.

## Output

- Case Card;
- counterfactual twin group;
- baseline packet;
- review record;
- failure-attribution hypothesis;
- explicit reasons for any remaining ambiguity.

## Rejection signals

Reject or rewrite when:

- the current turn alone contains the required behavior;
- twins do not require different output regions;
- the probe evidence contract depends mainly on an author’s unacknowledged interpretation;
- a universal relationship norm replaces case-local evidence;
- one architecture is required without being declared;
- the case needs hundreds of irrelevant events to appear difficult;
- reviewers cannot explain the must/must-not boundary.
