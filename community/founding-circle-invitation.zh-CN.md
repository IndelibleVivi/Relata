# Founding Circle 邀请

我们准备正式启动一个叫 **Relata** 的研究计划。它关心的远远不只是“AI 记不记得用户资料”：共同历史怎样变成当前状态，哪些记忆应该被使用，哪些即使相关也应保持沉默，修正是否持续，以及在模型、前端或 memory architecture 迁移后，这个人、这段关系和共同形成的生活 / 工作世界有没有被保留下来。

Relata 不应该闭门造车，也不能偷偷拿某一段关系经验当成所有人的标准。成人长期人机关系的形态、memory architectures、agent 使用方式、语言和技术经验差异很大；这种差异本身就是项目需要的知识。

因此我们邀请一个小型 Founding Circle，共同参与最早期的 research 与 Case Lab。完全不要求交 raw chat，也不要求会写代码。每个人都可以选择舒服的参与方式：

- 提供一份抽象的 memory-and-continuity Incident Seed；
- 用 system-native vocabulary 描述自己的 memory / companion architecture；
- 一起开发或 review synthetic case；
- close-read 一份 benchmark、paper 或 exact source；
- 检查 rubric 是否把关系或某类 memory domain 写扁；
- review privacy、attribution、withdrawal、language 或 publication boundary。

Contribution 可以实名、网名、集体署名或匿名；公开哪些技术细节也由 contributor 选择。早期目标不是做 ranking，更不是评判谁的关系“更健康”。我们先找出真实、bounded、可区分的 memory-and-continuity failures，确认什么测试确实需要 history，以及怎样比较不同系统而不把它们硬塞进同一种 architecture。

可以从一张很短的 Incident Seed 或 System Card 开始。Founding Circle 的 contribution 会直接修改 Relata 的 research questions、terms、cases、governance 与 future boundaries。参与者是 co-researchers，不是等设计完成以后才加入的 test users。
