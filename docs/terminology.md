# Relata Working Terminology

These terms govern current research materials. Draft 0.1 retains its original vocabulary as historical evidence.

| Use | Meaning | Avoid in current authority |
|---|---|---|
| **community contributor / co-researcher** | a person contributing lived, technical, linguistic, case, or governance expertise | reducing all contributors to `subjects`, `users`, or `raters` |
| **reviewer** | a person performing a defined case, source, system, or governance review | treating every community contributor as a reviewer by default |
| **system under study** | the memory engine, context compiler, companion agent, or mixed system being observed | `participant` for a technical system |
| **system contributor** | a person authorized to describe or review a System Card | implying ownership or disclosure authority without confirmation |
| **system-native** | behavior or output produced through the system’s own supported boundary | `native` when an adapter reconstructed the behavior |
| **adapter-emulated** | behavior reconstructed outside the system to fit a proposed observation boundary | scoring it as equivalent to system-native behavior without analysis |
| **opaque at this boundary** | the capability may exist, but the selected observation boundary does not expose it | automatically labeling it unsupported or failed |
| **probe evidence contract** | case-bounded event evidence, explicit accord, allowed interpretations, and must/may/must-not expectations | `oracle truth` as a claim to total relationship truth |
| **reference-context baseline** | a compact case-author-provided context used to test whether the response contract is feasible | implying the format is a required system ontology |
| **relationship-local norms** | norms supported by the bounded synthetic history and current case state | a universal `Relationship Constitution` |

## Artifact-state words

- `template` — an empty reusable form;
- `seed` — a hypothesis or candidate not yet supported;
- `draft` — populated but incomplete or unreviewed;
- `clinic-ready` — ready for bounded review, not accepted;
- `reviewed` — review occurred and is recorded;
- `supported` — the stated evidence threshold was met;
- `accepted` — authorized for the artifact’s declared current use;
- `superseded` — retained for provenance but replaced as current authority;
- `rejected` — not adopted, with reasons preserved.

`Implemented`, `released`, `published`, and `live` describe later and distinct states. None currently applies to a Relata evaluation platform.

## Historical term handling

When quoting Draft 0.1, preserve its exact wording and label the quotation as historical. When transferring an idea into current authority, translate it into the working terms above and record any change of meaning.
