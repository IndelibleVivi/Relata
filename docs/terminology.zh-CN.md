# Relata Working Terminology

这些 terms 管理当前 research materials。Draft 0.1 作为 historical evidence 保留原 vocabulary。

| 使用 | 含义 | 当前 authority 中避免 |
|---|---|---|
| **community contributor / co-researcher** | 贡献 lived、technical、linguistic、case 或 governance expertise 的人 | 把所有 contributors 都简化成 `subjects`、`users` 或 `raters` |
| **reviewer** | 执行明确定义的 case、source、system 或 governance review 的人 | 默认把每位 community contributor 都当 reviewer |
| **system under study** | 被观察的 memory engine、context compiler、companion agent 或 mixed system | 用 `participant` 指 technical system |
| **system contributor** | 获得授权描述或 review System Card 的人 | 未确认时暗示 ownership 或 disclosure authority |
| **system-native** | 通过 system 自己支持的 boundary 产生的 behavior / output | adapter 重建 behavior 时仍称 `native` |
| **adapter-emulated** | 在 system 外重建、以适配 proposed observation boundary 的 behavior | 未分析便按 system-native equivalent scoring |
| **opaque at this boundary** | capability 可能存在，但 selected observation boundary 不暴露它 | 自动标记为 unsupported 或 failed |
| **probe evidence contract** | case-bounded event evidence、explicit accord、allowed interpretations 与 must/may/must-not expectations | 用 `oracle truth` 声称 total relationship truth |
| **reference-context baseline** | case author 提供的 compact context，用于检查 response contract 是否 feasible | 暗示其 format 是 required system ontology |
| **relationship-local norms** | 由 bounded synthetic history 与 current case state 支持的 norms | universal `Relationship Constitution` |
| **deployment domain** | Relata questions 所处的长期 setting / population；当前是成人长期人机亲密与浪漫 | 把它当成 memory content eligibility restriction |
| **memory content domain** | continuity-bearing material 的类别：personal/lived、shared-relational、operational/project、companion/system 或 combination | 假定 content domain 决定 storage architecture |
| **use domain** | memory 可能影响 behavior 的 activity，例如 private conversation、group conversation、coding、research、planning 或 roleplay | 把一个 surface 当成整段关系 |
| **coverage stratum** | case portfolio 的 `personal-lived`、`shared-relational`、`operational-project`、`companion-system` 或 `mixed-domain` coverage label | 永久 benchmark track 或 mutually exclusive ontology |
| **continuity-bearing material** | 任何能随时间影响 continuity 的 retained、reconstructed、inferred 或 externally maintained material | 要求一定存在 inspectable discrete memory object |
| **memory ecology** | 支撑 longitudinal continuity 的 personal、relational、operational 与 companion/system material / processes 的互动 | 单一 undifferentiated user profile |
| **relational memory** | 位于 ongoing relationship 中的 memory；remembered object 不必显式谈关系 | intimacy-specific content only |
| **mixed-domain routing** | 决定跨 content domains 的 material 应进入哪个 role、surface、project、person 或 instance | 把所有 relevant items 广播到所有地方 |
| **scope contamination** | 邻近 project、role、person、surface 或 authority 的 material 进入不适合的 context，变得 distracting、private、stale 或 misleading | 把每个 cross-domain association 都叫 contamination |
| **ordinary-event continuity** | 忠实保留并使用日常信息，不强造 symbolic interpretation | 为让 ordinary event 看起来 evaluable 而发明 relational significance |
| **operational/project continuity** | project state、artifacts、decisions、rationale、milestones、handoffs、blockers 与 unfinished work 的 continuity | 只把 shared work 简化成 generic factual recall |

## Artifact-state words

- `template` — 空白 reusable form；
- `seed` — 尚未有 support 的 hypothesis / candidate；
- `draft` — 已填充但 incomplete 或 unreviewed；
- `clinic-ready` — 可进入 bounded review，但未 accepted；
- `reviewed` — 已发生并记录 review；
- `supported` — 达到明确 evidence threshold；
- `accepted` — 已授权用于 artifact 声明的 current use；
- `superseded` — 为 provenance 保留，但不再是 current authority；
- `rejected` — 未采用，并保留 reason。

`Implemented`、`released`、`published` 与 `live` 是更晚且互不等价的 states。当前 Relata evaluation platform 不符合其中任何一个。
