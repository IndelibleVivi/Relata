# Vision Documents

Files in this directory preserve ambitious proposals, speculative architectures, and long-horizon product ideas.

They are intentionally useful for imagination and adversarial review. They are not current implementation authority.

A vision claim becomes active only when it is:

1. supported by research or pilot evidence;
2. recorded in [`ASSUMPTION_REGISTER.md`](../../ASSUMPTION_REGISTER.md) or a decision record;
3. compatible with the current [charter](../../CHARTER.md), [status](../../STATUS.md), and governance boundary.

The original Draft 0.1 body is preserved in [`relata-target-architecture-draft-0.1.md`](relata-target-architecture-draft-0.1.md). Its authority banner and this index are current editorial framing; the body remains historical text.
