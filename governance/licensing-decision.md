# Licensing Decision — Open

Relata has not selected a license during R0. The source repository is public, but public visibility is not an open-source or open-content license grant.

Before public release, decide separately for:

- source code;
- specifications and documentation;
- synthetic case data;
- contributor-authored System Cards and reviews;
- generated evaluation artifacts.

Decision questions:

- Is broad reuse with attribution the primary goal?
- Should derivative casebooks remain under the same terms?
- How will contributor attribution be preserved in bulk datasets?
- Are model-generated portions identified separately?
- Does the project require a contributor agreement or only per-contribution licensing confirmation?
- How will withdrawn material be handled in future releases while preserving repository history honestly?

Do not add a default license merely to make the repository look complete. Record the final choice in a decision record before public publication.
