# Public / Private Boundary

## Zone A — Public research repository

The current Zone A repository is `https://github.com/IndelibleVivi/Relata`.

May contain:

- charter, research questions, and methods;
- exact-source Evidence Cards based on public material;
- contributor-approved System Card summaries;
- adult synthetic cases;
- de-identified aggregate insights;
- public decision and review records;
- reproducible pilot artifacts that contain no private source material.

Must not contain:

- raw private conversations;
- credentials or private infrastructure details;
- contributor identity beyond chosen attribution;
- private system configuration supplied under restricted visibility;
- consent records containing identifying information.

## Zone B — Restricted contributor workspace

May contain:

- circle-only System Cards;
- de-identified Incident Seeds;
- pre-publication synthetic derivations;
- consent status references;
- private review notes.

Access should be limited to the people needed for the specific contribution.

Zone B is not a tracked directory in the public research repository. Its storage platform, steward, access list, retention policy, and incident procedure remain an open maintainer decision that must be resolved before contribution collection.

## Zone C — Contributor-local source

May contain raw chats, local traces, private memory databases, prompts, or architecture material. Relata does not require upload or central storage of this zone.

## Derivation path

```text
local source
→ contributor-authored abstract Incident Seed
→ reviewed distinction
→ adult synthetic case
→ contributor review where promised
→ public release
```

The public case should not claim to reproduce the contributor’s relationship. Its provenance records the derivation class and consent mode, not the private source text.

Use `consent mode` rather than implying that permission levels form a progression. Public provenance may name the mode and contribution ID only when doing so does not create an identity link.

## Data minimization

Collect only what is needed to support the research claim. A vivid detail that does not change the distinction should be removed.

## Formal-study boundary

These zones govern collaboration and project publication. They do not determine whether a later activity is human-participant research or satisfy any institutional review requirement. That determination must be made separately before formal recruitment or data collection.
