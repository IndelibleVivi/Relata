## 当前 research target

Relata 正在用可 inspect 的 evidence 建立：

1. 成人长期、mixed-role 人机关系中，哪些 memory-and-continuity constructs 可以被 bounded evaluation；
2. 哪些 failures 确实需要 memory 才能区分；
3. 哪种 observable boundary 能比较 materially different systems，又不隐藏 architecture pressure；
4. 哪些 judgments 可以 deterministic，哪些需要 bounded semantic review，哪些属于 legitimate disagreement；
5. 长期人机关系 contributors 如何共同设计这个 field，而无需交出 raw private conversations。

## Working promotion gate

在以下条件满足前，不应 accept implementation-boundary decision：

- 至少五个 bounded distinctions 获得 multi-source support；
- 至少三个 materially different systems 有 reviewed System Cards 与 boundary analysis；
- 至少一张 pilot case 通过 Memory Necessity Gate；
- ordinary-life、operational/project、shared-relational 与 mixed-domain routing / isolation cases 各自至少运行过一次，才可提出 full-scope coverage claim；
- reviewer disagreement 已被记录并用于修改 rubric；
- consent-to-synthetic-publication path 至少在不转移 raw chat 的条件下走通一次；
- proposed boundary 有 accepted decision record，明确 excluded systems 与 adapter distortion。

这些计数是防止 premature implementation 的 governance thresholds，不是经过 validation 的 scientific sample-size claims。Evidence 可以通过 decision record 修改它们。
