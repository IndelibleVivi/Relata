# ADR-0012: Fixed continuation-use study

- **Status:** Accepted bounded execution commission, 2026-11-07.
- **Authority:** The maintainer explicitly commissioned the proposed longitudinal continuation study, selected the existing official OpenAI API resource and approved using both proposed model configurations. This records that commission; it does not derive provider authority from earlier studies.
- **Canonical packet:** [Continuation-use study](../research/continuation-use/README.md).

## Decision

Implement and execute one fixed original adult-synthetic study with 12 development histories and 48 frozen comparison histories. Each has six episodes and three later tasks. Memory formation does not receive the later tasks or author criteria. Compare current-only, original-history hybrid search, rolling summary with the same search, agent working notes with the same search, and full-history reference. Use official `gpt-6.1-sol` and `gpt-6-luna` readers, fixing the main writer to Sol. These are controlled replay conditions, not claims that authored assistant turns were generated by the memory writer or that an independent Tilia implementation is under test.

The named implementation may prepare materials, form memory, create a new fixed `text-embedding-3-small` / 1536-dimensional synthetic index, obtain responses, produce blinded AI-assisted criterion reviews, and compute descriptive paired analyses. The whole-history unit and shared construction must remain visible; request counts are not independent sample counts. Selected diagnostic interventions may explain observed gaps but must be labelled conditional and separate from the frozen comparison. Metabolism and authorship remain distinct research questions rather than assumed benefits of the notes condition.

The finite engineering envelope is at most 6,000 generation dispatches and 300 embedding dispatches, including development, material generation, validation/repair, review, failures and diagnostic requests. The coordinator-selected local cost ceiling is USD120 using conservative per-request reservations and returned usage. This is an execution bound within the maintainer's commission, not a verified account balance or invoice. Generation bodies are capped at 131,072 UTF8 bytes, outputs at 12,000 tokens for material creation and 4,096 otherwise. Study prompts remain below 32,768 reported input tokens; exceeding that stops further dispatch. No recharge, account-setting change or provider fallback is part of the commission.

## Evidence and recovery

Runtime configuration, immutable request/response records, ledger, generated drafts, reviews and result reports remain outside the checkout. Persist dispatch before sending; bind resumptions to exact request and study inputs. Do not automatically reissue uncertain requests. Known HTTP failures may have at most two explicit retries within the same cumulative envelope; preserve all attempts. Empty, incomplete, invalid and failed responses are distinct from semantic judgments. Model aliases and returned identity must be recorded; an alias is not an immutable snapshot.

The fixed offline core and transport belong to this study only. No arbitrary corpus, provider registry, cross-system runner, benchmark promotion, model-judge acceptance, independent human calibration, human recruitment, Tilia product change, hosting, release or result publication follows. Public source materials and tooling can be maintained under ordinary repository Git authorization; raw runs and private interpretations are not included. A later publication needs selected evidence and its own authority.

## Consequences

This study can provide inspectable episodes, counterexamples and conditional design implications for long-form memory inquiry and independent incubation. It cannot establish consciousness, felt continuity, general memory superiority, or the quality of real long-term relationships. Strong original-history and current-only controls can defeat a proposed memory benefit.
