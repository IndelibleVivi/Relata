# ADR-0005 — Permit Replaceable Offline Pilot Tooling

**Status:** accepted for the maintainer-authorized engineering scope on 2026-09-09; no research protocol accepted
**Scope:** bundled public synthetic rehearsal and repository checks

## Decision

The maintainer authorized implementation following the source review, on an independent branch, without merge, deployment, real data, or paid model calls. Within ADR-0001's allowance for validity and reproducibility tooling, Relata may execute the bundled RC-002 transport fixture using an explicitly scripted double, preserve step/input/output evidence, validate its binding, and export a blind-review packet.

This scope does not wait for submitted scores, external System Cards, or completed human calibration. It does not open a general agent API, provider integration, private-data import, public score registry, or benchmark runner. The script interface and local evidence format are replaceable engineering details, not an accepted cross-system observation or scoring contract.

## Limits

Only bundled invented adult material is admitted by the CLI. No credentials, model calls, external commands, arbitrary adapters, or private material are needed. Every result must identify itself as a scripted plumbing rehearsal. Case statuses, the six unsupported distinction hypotheses, reviewer calibration, and system capability evidence are not promoted by these tests.

The promotion gate continues to govern an accepted cross-system implementation boundary and public research claims. Formal protocol, model execution, private regression, release, and broader architecture comparisons need their own decisions or authorization. This exception cannot be used to smuggle them into R0.

## Consequences and reversal

The first implementation is deliberately one local script and one scripted subject. It has no third-party dependencies or automatic retry/resume. A new attempt uses a new output directory; interrupted or malformed evidence is retained or rejected, never quietly upgraded to completion.

Source-audited system descriptions, additional cases, and human review can proceed in parallel. No new evidence count or scientific sample-size threshold is established here. Remove or replace this tooling when pilot evidence supports a better execution boundary; preserve the previous source identity and old run records.
